# INPICK 실별 공사 패키지 견적 표준

- 기준일: 2026-07-24
- 적용 대상: 한국판 INPICK `workflow/estimate`의 세부내역서
- 상태: 로컬 구현·검증 완료, 운영 배포 전

## 1. 문제와 원인

기존 거실 견적은 강마루 공사를 다음 6개 원가 라인으로 계산하고 있었다.

1. 기존 바닥재 철거
2. 바탕면 정리 및 평활 보수
3. 방습지·접착제·부자재
4. 강마루 시공
5. 걸레받이 시공
6. 바닥재 폐기물 반출

원가를 이처럼 작업단계별로 계산하는 것은 잘못이 아니다. 문제는 상품 resolver가 모든
하위 라인의 `itemNameKo`를 최종 선택 자재인 `강마루`로 덮어썼고, 실별 화면이 이 원가
라인을 그대로 노출했다는 점이다. 그 결과 사용자는 동일한 강마루가 6번 과금되는 것으로
인식하게 됐다. 벽과 천장 도배도 같은 이유로 각각 4개의 동일 품명처럼 표시됐다.

## 2. 공개 기준에서 확인한 표기 원칙

### LH 실내재료마감표

[LH BIM 기반 설계 BP도면](https://lh.or.kr/boardDownload.es?bid=0027&list_no=721948&seq=17)은
실별 마감을 `AF 바닥`, `AB 걸레받이`, `AW 벽`, `AC 천장`으로 나눈다. 공개 도면의 거실
예시는 다음과 같은 구조다.

| 코드 | 부위 | 바탕 | 마감 |
| --- | --- | --- | --- |
| AF-02 | 바닥 | 패널히팅 | 강화합판마루 |
| AB-02 | 걸레받이 | 콘크리트/석고보드 | PVC 기성품 걸레받이 |
| AW-02 | 벽 | 콘크리트/석고보드 | 실크도배지 |
| AC-02 | 천장 | 경량철골 천장틀/석고보드 | 실크도배지 |

따라서 INPICK의 기본 실별 화면도 `실 × 부위 × 마감시스템`을 대표 계약 항목으로 사용한다.
걸레받이는 바닥 패키지에 숨기지 않고 별도 항목으로 표시한다.

### KCS 공사 분류

[국가건설기준센터 KCS 자료](https://www.codil.or.kr/filebank/original/RK/OTKCRK220591/OTKCRK220591.pdf)는
수장공사를 `KCS 41 51 02 바탕공사`, `KCS 41 51 03 바닥공사`,
`KCS 41 51 04 벽공사`, `KCS 41 51 05 도배공사`로 구분하고
`KCS 41 52 00 천장공사`를 별도로 둔다. 대표행 아래에 바탕과 마감의 작업단계를
보존해야 하는 근거로 사용한다.

### 예정가격 작성기준

[국가법령정보센터의 2026년 예정가격 작성기준](https://law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000272430)은
원가를 재료비·노무비·경비·일반관리비·이윤으로 구분하고, 재료량·노무량·소요량과
단위당 가격을 근거로 계산하도록 한다. 세부 분류가 가능한 공종을 근거 없는 `1식단가`로
작성하지 않는 원칙도 명시한다.

따라서 고객 화면에서 한 줄로 합치더라도 내부 원가를 없애거나 불투명한 일식 금액으로
바꾸면 안 된다. 대표 공사 1행과 그 안의 세부 산출근거를 함께 제공해야 한다.

### 2026년 조달청 제비율

[조달청 2026년 시설공사 간접공사비 적용기준](https://pps.go.kr/kor/bbs/view.do?bbsSn=2604070010&key=00038)은
2026-04-13 입찰공고분부터 변경된 간접노무비율과 기타경비율을 적용한다고 안내한다.
실별 직접공사비 패키지와 제비율·일반관리비·이윤·VAT 계산은 서로 다른 계층으로 유지한다.

### 공개 데이터의 한계

[나라장터 계약과정통합공개 API](https://www.data.go.kr/data/15129459/openapi.do?recommendDataYn=Y)는
공고·낙찰·계약 진행정보를 제공하지만, 민간 1군 건설사의 내부 협력업체 계약 일위대가와
전체 BOQ가 항상 공개되는 것은 아니다. 따라서 “1군 내부 계약서를 직접 분석했다”고
표현하지 않는다. 이번 표준은 공개 검증 가능한 LH 도면, KCS, 국가계약예규, 조달청 기준을
기준선으로 삼았다.

## 3. INPICK 표시 모델

### 정식 견적 문서 순서

기본 진입 화면은 세부내역서가 아니라 견적 갑지다. 화면과 출력 문서는 다음 순서를
공통으로 사용한다.

1. 갑지: 견적번호, 견적일, 유효기간, 발주처·시공사, 공사명·장소·기간, 도급금액, 특기사항, 날인란
2. 공사원가계산서: 직접재료비, 직접노무비, 직접경비, 간접노무비, 제경비, 일반관리비, 이윤, VAT
3. 총괄내역서: 공종별 재료비·노무비·직접경비·간접비 안분·공급가액
4. 세부내역서: 품명, 규격, 단위, 수량과 재료·노무·경비의 단가·금액
5. 공정표: 공종별 선후관계와 예상 공사기간

`ConstructionEstimate`의 경비를 노무비에 합쳐 표시하지 않는다. 모든 계층에서
`재료비 + 노무비 + 직접경비 = 직접공사비`가 성립해야 하며, 보험료·안전관리비 같은
제경비는 직접경비와 구분한다. 민간 소규모 인테리어 화면에서는 공공공사 제비율을 기본
비활성화하고 사업자가 필요할 때만 포함한다.

### 고객 기본 화면: 실별

거실 예시는 다음 4개 계약 항목으로 표시한다.

| 실 | 부위 | 대표 품명 | 대표 수량 |
| --- | --- | --- | ---: |
| 거실 | 바닥 | 강마루 바닥 마감공사 | 순바닥면적 25.2m² |
| 거실 | 걸레받이/몰딩 | 걸레받이 시공 | 둘레 21.0m |
| 거실 | 벽 | 실크벽지 벽 마감공사 | 순벽면적 42.0m² |
| 거실 | 천장 | 실크벽지 천장 마감공사 | 순천장면적 25.2m² |

대표행의 단가는 다음과 같이 표시한다.

- 재료환산단가 = 패키지 전체 재료비 ÷ 대표 순면적
- 노무환산단가 = 패키지 전체 노무비 ÷ 대표 순면적
- 경비환산단가 = 패키지 전체 직접경비 ÷ 대표 순면적
- 환산단가는 서로 다른 단위의 하위 공정을 비교하기 위한 표시값이며 원가 원본을 대체하지 않는다.

### 세부 산출근거

대표행의 `세부 산출근거 보기`에서 다음 정보를 제공한다.

- 실제 작업명
- 작업별 수량과 단위
- 수량 산식
- 재료비
- 노무비
- 경비
- 작업별 합계

강마루 바닥 대표행은 걸레받이를 제외한 다음 5개 하위 공정을 포함한다.

| 작업 | 수량 기준 | 용도 |
| --- | --- | --- |
| 기존 바닥재 철거 | 순바닥면적 | 철거 노무·경비 |
| 바탕면 정리 및 평활 보수 | 순바닥면적 | 바탕 상태 보수 |
| 방습지·접착제·부자재 | 발주면적 | 손실률 포함 부자재 |
| 강마루 시공 | 발주면적 | 선택 마감재와 시공 |
| 바닥재 폐기물 반출 | 폐기물 추정량 | 반출 노무·경비 |

### 사업자 공종별 화면

공종별 화면에는 철거·바탕·부자재·마감·폐기물의 원가 라인을 합치지 않고 유지한다.
사업자는 이 화면에서 실측 수량과 재료·노무·경비 단가를 수정한다. 수정된 원가의 합계는
실별 대표 패키지에 다시 반영된다. 입찰 화면에서는 동일한 정식 견적 문서와 공정표를
`사업자 편집` 상태로 제공한다. 사업자가 조정한 원가 라인, 공정별 시작일차와 기간,
최종 공사기간은 입찰의 `metadata.estimateDocument`에 함께 저장한다.

### 욕실 표시와 산출

욕실은 ‘욕실 전체 1식’ 한 줄로 계산하지 않는다. 바닥과 벽은 실제 면적 기반 마감
패키지로 표시하고, 위생기구·천장·전기·설비는 제품 또는 시공 포인트별로 표시한다.

| 구분 | 세부 산출 |
| --- | --- |
| 바닥 | 타일 철거, 방수, 타일 발주·시공, 줄눈 |
| 벽 | 벽 타일 철거, 벽체 방수, 벽 타일 발주·시공, 줄눈 |
| 설비 | 급수·온수 3포인트, 배수·트랩 3포인트, 수압·통수·누수시험 |
| 전기 | IP44 방우 콘센트·스위치, 방습 LED 조명, 환풍기 전원·스위치 |
| 위생기구 | 양변기, 세면대·하부장·수전, 샤워수전, 샤워파티션, 액세서리 |
| 천장·환기 | SMC 천장 면적, 저소음 환풍기 1대 |

욕실 `fixture` 계획은 욕실당 한 건만 전개한다. 바닥·벽 타일과 방수는 해당 부위
SurfacePlan에서 이미 계산되므로 욕실 전체 패키지에 다시 포함하지 않는다.

### 주방 표시와 산출

주방은 싱크대 전체 금액을 하나의 `set`으로 계산하지 않고 KitchenPlan의 실제
조리대 길이와 제품 개수로 분해한다.

| 구분 | 세부 산출 |
| --- | --- |
| 가구 | 하부장 m, 상부장 m, 키큰장 개수 |
| 상판·기기 | 상판 m, 싱크볼, 수전, 후드, 인덕션 쿡탑 각각의 개수 |
| 벽 마감 | 백스플래시 실제 m² |
| 설비 | 냉수·온수 2포인트, 싱크 배수·트랩, 식기세척기 급배수 |
| 전기 | 조리대 콘센트 개수, 인덕션 전용회로, 식기세척기·오븐 전용회로, 작업등 |

사용자가 범용 ‘싱크대’ 상품을 선택했을 때 그 단가를 상부장·상판·후드·쿡탑에 반복
적용하지 않는다. 범용 선택 단가는 하부장 대표 품목에만 적용하고, 나머지는 각 부품의
카테고리 단가를 사용한다. 후드와 인덕션도 서로 다른 제품·단가·수량으로 유지한다.

주방장·붙박이장·신발장·키큰장의 기본 브랜드는 한샘·리바트 같은 특정 대형 브랜드로
고정하지 않는다. 기본 내역에는 `맞춤형`으로 표시해 지역 제작업체가 동일 규격으로
입찰할 수 있게 한다. 사용자가 실제 브랜드 제품을 선택했거나 상품 DB에서 제품이
확정된 경우에만 해당 브랜드·제품 스냅샷을 사용한다.

### 전기·설비 표시 원칙

전기공사(`tradeCode 04`)와 설비공사(`tradeCode 05`)는 욕실 또는 주방 SurfacePlan에서
파생되더라도 실별 화면의 부위를 각각 `전기`, `설비`로 강제 분류한다. 따라서
‘욕실공사’나 ‘주방공사’ 안에 비용이 숨지 않으며, 사업자 공종별 화면에서도 독립 합계와
원가 라인을 확인할 수 있다.

## 4. 수량 산출 규칙

| 목적 | 수량 | 적용 |
| --- | --- | --- |
| 대표 계약 수량 | 정미량 | 도면·실측으로 확인한 순바닥/순벽/순천장 면적 |
| 마감재 발주량 | 정미량 × 손실률 | 절단·패턴·파손을 반영한 구매량 |
| 걸레받이 | 실 둘레 − 확정 개구부 | 도면 미확정 시 둘레와 가정 표시 |
| 철거 | 정미량 | 기존 마감 제거 면적 |
| 폐기물 | 면적 기반 추정량 | 현장 반출조건 확인 후 사업자 수정 |
| 욕실 벽 타일·방수 | 벽 둘레 × 높이 − 문·창 개구부 | 욕실 벽 노출률을 0으로 만들지 않음 |
| 주방장 | KitchenPlan의 하부장·상부장·상판 길이 | 사용자 입력 > 도면 치수 > 면적 추정 순 |
| 급수·배수·전기 | 포인트 또는 회로 개수 | 기기 위치·분전반 용량 현장 확인 |

정미량과 발주량을 같은 수량처럼 표시하지 않는다. 대표행은 정미량을 사용하고,
세부 산출에서 발주량과 손실률을 보여준다.

## 5. 수량 기반 공정표 산정

### 30일 고정값 폐기

공정표는 `공종 공사비 ÷ 전체 공사비 × 30일`로 계산하지 않는다. 같은 금액이라도 실제
작업량과 품질 대기시간이 다르면 공기가 달라지기 때문이다. 공정표는 견적에 실제 포함된
라인만 읽어서 다음과 같이 계산한다.

```text
공종 작업일 = ceil(Σ(견적 수량 ÷ 해당 단위의 일당 시공량))
공종 달력일 = max(공종 작업일 + 후속공정 차단 품질대기일, 시방 최소기간)
전체 공기   = 공정별 시작일차와 종료일차의 최댓값
```

[국토교통부의 2026년 적용 건설공사 표준품셈·표준시장단가 공고](https://www.molit.go.kr/USR/NEWS/m_71/dtl.jsp?id=95091544&lcmspage=1)는
표준품셈을 단위작업별 투입 인력·장비와 작업조 기반 일당 시공량 기준으로 관리한다.
단일한 “인테리어 전체 표준 공사일수”가 있는 것은 아니므로, INPICK도 공종별 수량과
생산성을 합산하고 품질 대기시간을 별도로 더한다.

### 생성 예시

| 공사 범위 | 자동 예비 공정 |
| --- | --- |
| 거실 벽 42㎡ + 천장 25.2㎡ 도배 교체 | 철거 1일 + 도배 1일 + 청소·검수 1일 = 3일 |
| 욕실 바닥 4.2㎡ + 벽 17.5㎡ | 방수·담수시험 3일 + 타일·보양 3일 + 도기 설치 1일 = 핵심 7일 |

전체 리모델링은 투입 작업조와 실별 병렬시공 여부에 따라 달라진다. 자동값은 순차시공
기준 예비 공기이며, 사업자는 입찰 전 공정표에서 시작일차와 기간을 직접 수정한다.
수정한 공정표의 총일수가 입찰서 `estimated_days`와 견적 갑지 예상 공사기간에 반영된다.

## 7. 구현 불변조건

1. 실별 패키지화 전후의 직접재료비가 같아야 한다.
2. 실별 패키지화 전후의 직접노무비·경비가 같아야 한다.
3. 실별 패키지화 전후의 직접공사비 총액이 같아야 한다.
4. 최종 마감재 상품 resolver는 철거·바탕·부자재 라인을 덮어쓰지 않아야 한다.
5. 기존 저장 견적의 잘못된 `itemNameKo`가 있어도 실제 `taskNameKo`로 작업명을 복구해야 한다.
6. 공종별 화면과 문서 스냅샷에는 원가 라인이 남아 있어야 한다.
7. 걸레받이는 LH 마감표 구조에 맞춰 바닥과 별도 항목으로 표시해야 한다.
8. 욕실 위생기구 패키지가 바닥·벽 SurfacePlan 수만큼 반복되면 안 된다.
9. 욕실 바닥·벽의 타일·방수는 각각 실제 면적으로 한 번씩만 계산해야 한다.
10. 전기와 설비 라인은 생성 공간과 관계없이 각각 `전기`, `설비` 부위로 표시해야 한다.
11. 범용 주방 선택 단가를 상부장·상판·수전·후드·쿡탑에 복제하면 안 된다.
12. 주방 후드와 쿡탑은 서로 다른 제품, 수량, 단가 라인으로 유지해야 한다.
13. 견적 갑지에는 문서번호·갑/을·공사정보·유효기간·특기사항·날인란이 있어야 한다.
14. 직접경비를 노무비에 합산하거나 제경비와 중복 계상하면 안 된다.
15. 세부내역서의 재료비·노무비·경비는 각각 단가와 금액 열을 가져야 한다.
16. 공사비가 달라져도 견적 수량이 같다면 자동 공사기간이 달라지면 안 된다.
17. 방수 48시간 검사와 타일 3일 보양을 후속공정 전에 반영해야 한다.
18. 입찰 API는 임의의 30일을 기본값으로 저장하지 않아야 한다.
19. 견적 컨텍스트는 Step2의 실별 최종 선택 이미지 한 장과 그 이미지의 생성·수정 프롬프트만 사용해야 한다.
20. 같은 실의 선택하지 않은 과거 이미지에 붙은 Vision 자재 결과를 현재 이미지로 승계하면 안 된다.
21. Step2에서 사용자가 확정한 실제 `materialProductId`/SKU는 브라우저 상태에만 두지 않고 `userMaterialEdits`로 견적 컨텍스트에 포함해야 한다.
22. 선택 이미지 분석이 견적 최초 표시 뒤 완료되면 새 컨텍스트를 발급하고 17공종 견적을 한 번 자동 재합성해야 한다.
23. Step3 총액은 무료 공개하고, 세부견적·견적서·수량 기반 공정표·계약 확인 문서는 하나의 버전별 공개권으로 묶는다.
24. 통합 공개권은 20토큰(토큰 1개 500원 기준 약 1만원)이며 같은 견적 버전은 재차감하지 않는다.
25. 별도 9,900원 PDF 버튼을 소비자 Step3에 중복 노출하지 않는다.
26. 통합 PDF의 모든 상세 라인은 기본 펼침 상태로 출력하고, 페이지가 바뀌면 표 머리글을 반복해 행이 잘리지 않게 한다.

### Step1·2 → 견적 evidence 연결

`finalSelectedImageUrlsByRoom`이 있으면 그 실과 이미지가 최종 진실원이다. 없을 때만
`selectedByRoom`을 사용한다. 서버로 보내는 선택 이미지 evidence는 다음을 함께 보존한다.

- 최종 이미지 URL
- 해당 시안의 `revisedPrompt`와 원 생성 프롬프트
- 실별 프롬프트, 전체 콘셉트 프롬프트
- 사용자가 확정한 제품 ID, SKU, 규격, 단가 출처

DB 저장이 이미지 선택보다 늦게 끝난 경우에는 선택 이미지와 프롬프트로 임시 evidence를 만들고
프롬프트 자재 힌트를 우선 반영한다. 이후 정확히 같은 이미지 URL의 Vision 분석이 완료되면
견적 컨텍스트와 견적을 자동 재생성한다. 다른 이미지의 분석값은 같은 실이라는 이유만으로
복사하지 않는다.

### Step3 통합 공개권

견적 버전 식별자는 프로젝트 ID만 쓰지 않고 최종 이미지·프롬프트·선택 자재를 해시해 만든다.
같은 버전은 세부견적과 전체 문서를 반복 열람·다운로드할 수 있고, 최종 디자인이나 선택 자재가
바뀌어 견적 근거가 달라진 경우에만 새 버전으로 본다.

통합 PDF는 공정위 표준계약서 원본과 인픽 정식 견적 폼을 한 파일로 제공한다. 인픽 문서에는
갑지, 총괄표, 총괄내역, 전체 공종별 상세내역, 자재집계표, 산출근거, 수량 기반 공정표,
최종 디자인, 특기사항과 계약 확인·서명란이 포함된다.
19. 가구 기본값에는 특정 대형 브랜드 대신 `맞춤형`을 표시해야 한다.
20. 사업자가 수정한 견적 라인과 공정표는 입찰서에 함께 저장되어야 한다.
