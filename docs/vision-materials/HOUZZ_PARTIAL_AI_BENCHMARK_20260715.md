# Houzz 벤치마크 — 부분 AI 인테리어·자재·시공 연결

기준일: 2026-07-15

## 선정 이유

Houzz는 인테리어 이미지 탐색에서 제품 발견, 실내 미리보기, 전문가 연결까지 이어지는 흐름을 제공한다. Houzz 공식 소개에 따르면 300만 명 이상의 전문가와 7,000만 명 이상의 홈오너·디자인 관심 사용자 규모를 밝히고 있어, 미국 벤치마크 한 곳으로 선정했다.

- [Houzz About Us](https://www.houzz.com/aboutUs)
- [Houzz Visual Match](https://www.houzz.com/magazine/inside-houzz-find-products-for-your-home-with-visual-match-stsetivw-vs~73421107)
- [Houzz Pro Visualization Tools](https://pro.houzz.com/pro-learn/blog/how-remodelers-use-houzz-pro-visualization-tools)
- [Houzz Pro AI Tools](https://pro.houzz.com/pro-learn/blog/houzz-pro-puts-the-power-of-artificial-intelligence-to-work-for-you)

## 핵심 흐름

1. 이미지나 프로젝트에서 좋은 디자인을 발견한다.
2. Visual Match로 사진 안 객체와 비슷한 구매 가능 제품을 찾는다.
3. View in My Room·공간 시각화로 적용 결과를 미리 본다.
4. 제품 라이브러리, 무드보드, 플랜을 프로젝트 단위로 쌓는다.
5. 선택 내용을 전문가·시공 업무와 연결한다.

## 이번에 반영한 것

- 부분 AI 인테리어에서 렌더 결과, 실 유형, 면적, 스타일, 바닥·벽·천장 자재, 실별 옵션, 검색 키워드를 **선택 보드**에 함께 저장한다.
- 저장한 데이터는 후속 자재 상담·부분시공 업체 비교에 그대로 사용할 수 있다.
- 메인 화면에 iOS·Android 설치 카드를 넣어 웹에서 앱으로 자연스럽게 이동한다.
- AI 이미지 엔진 혼잡 시 같은 모델 1회 자동 재시도, 대체 모델 전환, 최종 실패 시 토큰 자동 환불을 적용한다.

## 다음 우선순위

1. 이미지 생성 완료 직후 SAM이 바닥·벽·천장 자동 핫스팟을 제안하고 사용자는 확정만 하는 흐름.
2. 자재 제조사용 CSV/API 입점: SKU, 브랜드, 카테고리, 이미지, 스펙, 권장가, 시공단가, 판매 지역.
3. 선택 보드를 소비자·제조사·시공사가 승인·대체안 제안할 수 있는 공유 단위로 확장.
4. 선택 자재 수량·시공 난이도·지역 단가를 입찰 요청 데이터로 자동 변환.
