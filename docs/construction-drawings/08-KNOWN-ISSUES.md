# 08. 현재 한계점 + 개선 방향 + 리스크

## 확인된 한계점

### 1. 입면도 계산 정확도

**문제**: 벽면 정렬이 시계방향 각도 기반이라 비직각 평면에서 벽면 라벨(A/B/C/D) 매핑이 부정확할 수 있음.

**영향**: 사선벽이 있는 아파트에서 입면전개도 벽면 순서가 실제와 다를 수 있음.

**대응**:
- 현재: 가장 가까운 직각으로 근사
- 개선: 벽 법선 벡터 기반 방향 판단 + 수동 라벨 수정 UI

### 2. 설비 크기 하드코딩

**문제**: 설비(세면대, 양변기 등) 크기가 고정값.

**영향**: 실제 제품 규격과 차이 → 입면도에서 설비 위치/크기 부정확.

**대응**:
- 현재: 한국 아파트 표준 평균값 사용
- 개선: 자재 DB와 연동하여 선택된 제품의 실제 규격 반영

### 3. 천장 높이 고정

**문제**: 모든 방 2400mm 고정.

**영향**: 복층, 높은 천장(2700mm+) 아파트에서 입면도 비율 부정확.

**대응**:
- 코드에 ceilingHeight 파라미터 존재하지만 외부에서 전달하는 구조 미완성
- 개선: 도면 인식 시 층고 자동 감지 또는 사용자 입력

### 4. 가구 배치 알고리즘 단순

**문제**: "가장 긴 벽에 붙이기" 수준의 단순 룰.

**영향**: 복잡한 평면(L자, 사선)에서 가구 겹침/동선 차단 발생 가능.

**대응**:
- 현재: Gemini AI가 사후 분석으로 보완
- 개선: 충돌 감지 + 반복 최적화 알고리즘 (constraint-based placement)

### 5. Vercel 타임아웃

**문제**: Hobby 플랜 10초 타임아웃. 도면 생성에 2-5분 소요.

**영향**: 프로덕션 배포 시 도면 생성 API 실패.

**대응**:
- 필수: Vercel Pro ($20/월) → 300초
- 대안: 도면 생성을 백그라운드 작업으로 분리 (Supabase Edge Function 또는 별도 서버)

### 6. SVG → PDF 변환 품질

**문제**: jsPDF는 SVG 네이티브 미지원. 래스터(PNG)로 변환 후 삽입.

**영향**: 인쇄 시 해상도 저하 가능.

**대응**:
- 현재: SVG → canvas → PNG → jsPDF
- 개선: pdf-lib + svg-to-pdfkit으로 벡터 직접 삽입

### 7. 전기 배치 누락 케이스

**문제**: 13개 방 타입만 규칙 정의. 다용도실/팬트리 등 비표준 방은 기본 규칙만 적용.

**영향**: 특수 공간의 전기 배치가 부정확.

**대응**:
- 현재: 기본값(스위치 1개 + 콘센트 2m당 1개) 적용
- 개선: 사용자 수동 배치 UI + AI 추천

## 리스크 매트릭스

| 리스크 | 확률 | 영향 | 대응 |
|--------|------|------|------|
| Gemini API 쿼터 초과 | 중 | 높음 | 캐싱 + 생성 횟수 제한 |
| 입면도 정확도 클레임 | 중 | 높음 | "참고용" 면책 + 수동 수정 기능 |
| Vercel 타임아웃 | 높 | 높음 | Pro 업그레이드 필수 |
| 3D 이미지 품질 미달 | 중 | 중 | MVP는 SVG만, 이미지는 향후 |
| PDF 인쇄 품질 | 낮 | 중 | 벡터 PDF 전환 |
| 비직각 평면 오류 | 낮 | 중 | 주요 타입(59/84A/84B)은 직각 |

## 개선 로드맵 (우선순위 순)

1. Supabase Storage 버킷 생성
2. Vercel Pro 업그레이드
3. 84B 타입 E2E 검증

### 중기 (서비스 안정화 후)
4. 설비 크기 DB 연동
5. 층고 파라미터 전달
6. 가구 배치 충돌 감지
7. 벡터 PDF 전환

### 장기 (사용자 피드백 기반)
8. 3D 렌더 이미지 품질 개선
9. 사용자 수동 편집 도면 에디터
10. DWG/DXF 직접 출력
11. 도면 버전 관리
12. 사업자 커스텀 도면 수정 기능

- PDF에 "본 도면은 AI 자동 생성이며, 실제 시공 시 전문가 확인이 필요합니다" 문구 추가 권장
- 전기 배치도는 한국전기안전공사 규정 기반이지만 **전기공사기사 확인 권장** 문구 필요
