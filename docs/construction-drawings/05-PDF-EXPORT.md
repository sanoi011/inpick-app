## 출력 규격

| 항목 | 값 |
|------|-----|
| 용지 | A3 가로 (420mm × 297mm) |
| 폰트 | NanumGothic Regular/Bold |
| 폰트 로드 | 런타임 fetch (`/fonts/NanumGothic-*.ttf`) |

## 도면 유형별 페이지 수 추정

| 도면 | 페이지 수 | 비고 |
|------|----------|------|
| 표지 | 1 | 고정 |
| 가구배치도 | 1 | 전체 평면 |
| 전기배선도 | 1 | 전체 평면 |
| 입면전개도 | 방 수 × 4벽면 | 84m² 기준 ~20장 |
| **합계** | **~23페이지** | 주요 5방만 → ~23장 |

## 이미지 로드 방식

```typescript
// SVG URL → 이미지 데이터
const imgResponse = await fetch(drawing.finalUrl || drawing.svgUrl);
const imgBlob = await imgResponse.blob();
const imgData = await blobToBase64(imgBlob);

// jsPDF에 삽입
doc.addImage(imgData, 'PNG', x, y, width, height);
```

- 이미지 로드 실패 시: 폴백 메시지 ("이미지를 불러올 수 없습니다")
- SVG → PNG 변환: 서버사이드에서 sharp 또는 canvas 사용

## 폰트 관리

```
public/fonts/
  ├── NanumGothic-Regular.ttf   (3.4MB)
  └── NanumGothic-Bold.ttf      (4.6MB)
```

- 다운로드 버튼 클릭 시에만 로드 (lazy loading)
- 총 ~8MB 다운로드 필요 → 첫 PDF 생성 시 2-3초 대기

## 구현 시 개선 사항

1. **SVG 직접 삽입**: jsPDF는 SVG 네이티브 미지원 → SVG→PNG 변환 필요
   - 현재: Supabase에 업로드된 이미지 URL fetch
   - 대안: 클라이언트에서 canvas로 SVG 렌더 → toDataURL

2. **벡터 PDF**: SVG를 벡터 그대로 PDF에 넣으려면
   - svg-to-pdfkit 또는 pdf-lib 라이브러리 검토
   - 인쇄 시 해상도 무관 장점

3. **워터마크**: 미결제 사용자는 워터마크 버전 제공 검토
