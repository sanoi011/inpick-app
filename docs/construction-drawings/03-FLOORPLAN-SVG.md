# 03. 평면도 SVG 도면 3종 생성 스펙

> 파일: `src/lib/floor-plan/drawing/svg-generators.ts` (549줄)

## 3종 도면

| 도면 | 함수 | 용도 |
|------|------|------|
| 가구배치도 | `generateFurnitureLayoutSVG()` | 방별 가구 배치 + 동선 확인 |
| 전기배선도 | `generateElectricalPlanSVG()` | 콘센트/스위치/특수 배선 |
| 입면전개도 | `generateElevationSVG()` | 벽면 전개 + 치수 + 자재 |

## 공통 스타일

- **배경**: 다크(#0D1117) — loom_drawings 참조
- **벽선**: 흰색(#FFFFFF)
- **치수선**: 회색(#8B949E) + 틱마크 + mm 텍스트
- **스케일**: 평면 0.15 px/mm, 입면 0.12 px/mm
- **캔버스**: 1200×900 SVG

## 1. 가구배치도

### 렌더링 레이어 (순서)
1. 방 채우기 (반투명)
2. 벽체 폴리곤 (흰색 외곽, 다크 채우기)
3. 개구부 (문: 주황 호, 창: 하늘색 이중선)
4. 가구 심볼 (직사각형 + 라벨)
5. 방 이름 + 면적 라벨

### 자동 가구 배치 (`autoPlaceFurniture`)
```
방 타입 → ROOM_DEFAULT_FURNITURE 매핑
  LIVING_ROOM → 3인 소파 + 커피테이블 + TV스탠드
  MASTER_BEDROOM → 퀸 침대 + 협탁×2 + 3문 옷장
  BEDROOM → 싱글 침대 + 협탁 + 책상 + 의자
  KITCHEN → 냉장고
  ENTRANCE → 신발장
  UTILITY → 세탁기
```

배치 알고리즘:
- 침대/옷장 → 가장 긴 벽면에 붙임
- 소파 → 가장 긴 벽 대면에 배치
- TV → 소파 대면 벽
- 중앙 가구(커피테이블) → 방 중심

## 2. 전기배선도

### 전기 심볼 색상
| 타입 | 색상 | 심볼 |
|------|------|------|
| 콘센트 | 주황 #FFA657 | 원 (r=10) |
| 스위치 | 초록 #56D364 | 사각 (8×8) |
| TV 단자 | 보라 #BC8CFF | 원 (r=12) |
| 데이터 | 하늘 #79C0FF | 원 |
| 특수 (에어컨/가스) | 분홍 #F778BA | 원 |

### 전기 배치 엔진 (electrical-placement.ts, 301줄)

13개 방 타입별 표준 규칙:

```
LIVING_ROOM:
  - 2로 스위치 (1200mm) → 입구 벽
  - TV 단자 (300mm) → 가장 긴 벽 중앙
  - LAN 단자 (300mm) → TV 옆
  - 에어컨 콘센트 (1800mm) → 긴 벽 끝

KITCHEN:
  - 1로 스위치 (1200mm) → 입구 벽
  - 상부장하 콘센트 ×4 (1050mm) → 순환 분배
  - 냉장고 콘센트 (2000mm) → 전용
  - 가스밸브 (450mm) → 싱크대 근처 벽
  - 레인지후드 콘센트 (1600mm)

BATHROOM:
  - 조명+환풍기 2로 스위치 (1200mm)
  - 방수 콘센트 (1200mm)
  - 환풍기 (2200mm)
```

추가 콘센트 자동 계산: 벽면 2m당 최소 1개
모든 방: 화재감지기 천장 배치 (2400mm)

## 3. 입면전개도

### SVG 구성 (위→아래)
```
[도면 제목 바] ── "거실 - A벽 입면전개도 | 3,400mm × 2,400mm"
[천장선 (점선)] ─────────────────────────────────
                |                               |
  [자재 주석]   |  [개구부]  [설비]  [전기심볼]  |  [세로 치수]
                |                               |
[바닥선 (실선)] ─────────────────────────────────
[가로 치수선] ── tick + mm 텍스트 + 개구부 구간 분리
[렌더 이미지 placeholder] (선택사항)
```

### 치수선 자동 생성
- **가로 치수**: 벽 전체 길이 + 개구부 사이 구간별 세분화
- **세로 치수**: 벽 높이 (2400mm 기본)
- 단위: mm
- 틱마크: 6px 직선

### 자재 주석
- 위치: 개구부 없는 벽면 영역
- 스타일: 파란 박스(#1A2332) + 텍스트(#58A6FF)
- 표시: "바닥: 원목마루" / "벽: 실크도배" / "천장: 석고보드"
